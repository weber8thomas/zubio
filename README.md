# Zubio

**Le bon coach, au bon créneau.** Vitrine de démonstration : une salle de sport publie un créneau, les coachs compatibles du coin postulent, la salle confirme son choix, puis valide la séance qui est facturée automatiquement. Lancement sur Bayonne, Anglet et Biarritz.

Démo en ligne : https://weber8thomas.github.io/zubio/

100 % statique : données fictives, état gardé dans le navigateur, aucune base de données.

```bash
npm install
npm run dev
```
